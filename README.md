# Vista Clinics

A static, responsive multi-page website concept for Vista Clinics, Moosapet, Hyderabad.

## Included

- Home, Cardiology, Gastroenterology & Hepatology, Diagnostics, Doctors, Booking, Reviews, Contact and About pages.
- Shared responsive black/white design system with restrained grey gradient accents.
- Mobile navigation and booking success modal.
- `config.json` as the clinic data source.
- GitHub Pages deployment workflow under `.github/workflows/pages.yml`.

## Booking

The current booking form is intentionally demo-only: it prevents a real submission and shows a confirmation modal. Before production use, connect it to the clinic's chosen booking provider or secure backend. Do not collect or transmit real patient information until the backend, privacy notice and security controls are in place.

## GitHub Pages

The repository includes a GitHub Actions Pages deployment. Pushes to `main` trigger deployment. The repository's Pages/Actions settings must permit GitHub Actions as the Pages source.

## Content note

The sample reviews are explicitly marked as samples. Replace them with verified reviews and confirm all clinic, doctor, service, address, phone and operating-hour details before publishing.
